## Description

Briefly describe what your project does.:
The sketch generates a random array using a function to create a maze. the function generating the array ensures that the level follwos the follwoing restrictions. The starting point is always in the top left corenr and the finish is in the bottom left, there is always a path for the player to move from the start to the finish without being blocked.

Once the level has generated a function will take the level and use it to produce a visual representation of the array using colours to designate features within the level. For instance black mean a barrier whic hthe palyer cannot move into, white defines an open space allowign the player to move into it, green is the start postion and blue is the end postion. The player can see where they are based on the red circle displaying their current positon in the game.

## Interaction Instructions

The game starts on its own and the palyer can move the red circle using the arrow keys. In order to win they must reach the blue square by navigating through the randomly generated level of the game. When they reach the blue square the game will end and a screen will appear telling them that they have won!
